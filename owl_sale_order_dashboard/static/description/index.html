Modern Sales Dashboard

Most Advanced Open-Source sales Dashboard

Overview

A comprehensive sales dashboard for Odoo that provides visual analytics and key performance indicators for your sales team. Features -------- - **Date Range Filtering:** Filter data by custom date ranges with a user-friendly interface. - **Key Performance Indicators (KPIs):** - Total Orders - Total Revenue - Best Selling Product - Top Performing Salesperson - Total Canceled Orders - Total Not Invoiced Orders - **Interactive Charts:** - Best Selling Products (Bar Chart) - Top Salespersons (Horizontal Bar Chart) - Order Status Overview (Pie Chart) - Payment Summary (Doughnut Chart) - **Responsive Design:** Works on desktop, tablet, and mobile devices. - **Real-time Data:** All data updates automatically when filters change.
