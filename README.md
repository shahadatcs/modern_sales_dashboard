# modern_sales_dashboard
Odoo Owl Modern Sales Dashboard

This repository demonstrates real-world customization and implementation in Odoo 18 Community Edition.

---

## 📦 Modules Overview

### 1. owl_sale_order_dashboard
An interactive Sales Order Dashboard built with **OWL (Odoo Web Library)** for real-time sales insights.

**Features:**
- 📊 Interactive charts (bar, line, donut) powered by OWL.
- 📅 Date range filtering custom.
- 📦 KPIs:
  - Total Sales Orders
  - Total Revenue
  - Canceled Orders
  - Not Invoiced Orders
- 🏆 Best-selling products and top-performing salespersons.
- 🔄 Real-time updates with Odoo models.

**Use Case:** Helps sales teams track performance visually and make informed decisions quickly.
